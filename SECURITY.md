# Security Policy

If you find a vulnerability in our software or systems, please report it privately. Do not open a public issue.

## Reporting

1. **Email** — [security@abdeen.industries](mailto:security@abdeen.industries).
2. **GitHub** — *Report a vulnerability* under the Security tab of the affected repository, if you can see it.

A useful report explains what you observed, where you saw it, and how to reproduce it. Include relevant requests, logs, or payloads when available.

## Response

| Step            | Commitment                    |
| --------------- | ----------------------------- |
| Acknowledgement | 72 hours                      |
| Verdict         | 14 days                       |
| Fix, disclosure | Coordinated with the reporter |

## Scope

Every repository in this organization and abdeen.industries.

Abdeen Labs software, abdeen.dev and the repositories at [github.com/abdeen-labs](https://github.com/abdeen-labs) follow the [Abdeen Labs security policy](https://github.com/abdeen-labs/.github/blob/main/SECURITY.md).

Good-faith research conducted within this policy is welcome and will not be met with legal action.
