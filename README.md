# .github

Organization profile for **Abdeen Industries**, the software development and cybersecurity company. `profile/README.md` renders on [github.com/abdeen-industries](https://github.com/abdeen-industries).

`profile/assets/` contains the Industries lockup and mark.

`SECURITY.md` at the repository root is the organization-wide security policy. Every repository in the organization inherits it unless it carries its own copy.
